# Rocky Linux 서버 기본 설정

## OS 정보 확인

```bash
cat /etc/os-release
```

## SELinux 로그 확인
```bash
sudo ausearch -m avc -ts recent
```

## SELinux 권한 확인
```bash
ls -Z /etc/redis/users.acl
```

## 타임존 설정

### 현재 시간 및 타임존 확인

```bash
timedatectl
```

### 타임존 변경 (한국 시간)

```bash
sudo timedatectl set-timezone Asia/Seoul
```

# PostgreSQL 18

## PostgreSQL 저장소 및 패키지 설치

```bash
# PGDG 저장소 RPM 설치
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# 기본 PostgreSQL 모듈 비활성화
sudo dnf -qy module disable postgresql

# PostgreSQL 18 설치
sudo dnf install -y postgresql18-server postgresql18-contrib
```

## postgres OS 계정 비밀번호 설정

```bash
sudo passwd postgres
```

> `su - postgres` 사용 시 필요

## 데이터베이스 초기화

Rocky Linux에서는 설치 후 별도 초기화가 필요하다.

### 기본 초기화

```bash
sudo /usr/pgsql-18/bin/postgresql-18-setup initdb
```

### initdb 직접 실행 예시

```bash
sudo -u postgres /usr/pgsql-18/bin/initdb \
-D /var/lib/pgsql/18/data \
--locale='C' \
--encoding='UTF8'
```

## 원격 접속 설정

### postgresql.conf 수정

```bash
sudo vi /var/lib/pgsql/18/data/postgresql.conf
```

```conf
# 모든 IP 허용
listen_addresses = '*'

# 특정 IP만 허용
# listen_addresses = '192.168.1.10,127.0.0.1'
```

### pg_hba.conf 수정

```bash
sudo vi /var/lib/pgsql/18/data/pg_hba.conf
```

```conf
# IPv4 Remote Connections
host    all             all             0.0.0.0/0               md5
```

## postgres 계정 비밀번호 설정

### PostgreSQL 접속

```bash
sudo -u postgres psql
```

### 비밀번호 변경

```sql
ALTER USER postgres PASSWORD 'postgres';
```

## 설정 파일 위치 찾기

```bash
sudo find / -name "postgresql.conf"
sudo find / -name "pg_hba.conf"
```

## 서비스 관리

### 상태 확인

```bash
sudo systemctl status postgresql-18.service
```

### 서비스 시작

```bash
sudo systemctl start postgresql-18.service
```

### 서비스 중지

```bash
sudo systemctl stop postgresql-18.service
```

### 서비스 재시작

```bash
sudo systemctl restart postgresql-18.service
```

### 부팅 시 자동 시작 활성화

```bash
sudo systemctl enable postgresql-18.service
```

### 부팅 시 자동 시작 비활성화

```bash
sudo systemctl disable postgresql-18.service
```

# Redis

## 저장소 및 패키지 설치

### Remi 저장소 설치

```bash
sudo dnf install -y https://rpms.remirepo.net/enterprise/remi-release-8.rpm
```

### 설치 가능한 Redis 모듈 확인

```bash
sudo dnf module list redis
```

### Redis 모듈 초기화

```bash
sudo dnf module reset redis
```

### Redis 8.8 설치

```bash
sudo dnf module install -y redis:remi-8.8
```

## Redis 설정

### redis.conf 수정

```bash
sudo vi /etc/redis/redis.conf
```

```conf
# ip허용
bind 0.0.0.0 -::1

# default 계정 기본 비밀번호 세팅
requirepass redis

# ACL 파일 경로
aclfile /etc/redis/users.acl
```

## ACL 파일 생성

```bash
sudo semanage fcontext -a -t redis_var_lib_t '/etc/redis(/.*)?'
sudo restorecon -Rv /etc/redis
```

```bash
sudo touch /etc/redis/users.acl
sudo chown redis:redis /etc/redis/users.acl
sudo chmod 640 /etc/redis/users.acl
```

## Redis 서비스 시작

```bash
sudo systemctl enable --now redis
```

## Redis ACL 설정

### Redis 접속

```bash
redis-cli
```

### default 계정 비밀번호 설정

```redis
ACL SETUSER default >redis
```

### 별도 계정 생성

```redis
ACL SETUSER redis on >redis ~* +@all
```

### ACL 저장

```redis
ACL SAVE
```
